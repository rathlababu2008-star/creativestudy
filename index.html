JEE Preparation

Physics • Chemistry • Maths

⚙️ Physics — Kinematics

v = u + at
s = ut + ½at²
v² = u² + 2as
Example: u=0, a=2 m/s², t=5 s → v=10 m/s.

🧲 Physics — Laws of Motion

F = ma
p = mv
Impulse = FΔt = Δp
Tip: Always draw a free-body diagram.

🔋 Physics — Work, Energy & Power

W = Fs cosθ
K.E. = ½mv²
P = W/t

🌍 Physics — Gravitation

F = GMm/r²
g = GM/R²
vₑ = √(2GM/R)

🧪 Chemistry — Mole Concept

n = m/M
N = nNₐ
Molarity = moles / volume(L)

⚛️ Chemistry — Atomic Structure

Eₙ = −13.6/n² eV (hydrogen)
λ = h/p

🔗 Chemistry — Chemical Bonding

Review ionic, covalent, coordinate bonds, VSEPR and hybridisation.

Tip: Draw Lewis structures before deciding geometry.

🧴 Chemistry — Acids & Bases

pH = −log[H⁺]
pOH = −log[OH⁻]

📐 Maths — Quadratic Equations

x = (−b ± √(b²−4ac))/2a
D = b²−4ac

📐 Maths — Trigonometry

sin²θ + cos²θ = 1
1 + tan²θ = sec²θ

∂ Maths — Differentiation

d(xⁿ)/dx = nxⁿ⁻¹
d(sin x)/dx = cos x

🎲 Maths — Probability

P(A) = favourable outcomes / total outcomes
P(A') = 1 − P(A)

NEET Preparation

Biology • Physics • Chemistry

🧬 Biology — Cell

Cell membrane controls transport. Nucleus stores genetic material. Mitochondria are major sites of ATP production.

Tip: Revise organelle function + diagrams together.

🫀 Biology — Human Physiology

Focus on digestion, breathing, circulation, excretion and neural/endocrine coordination.

🌱 Biology — Plant Physiology

Revise photosynthesis, respiration, transport, mineral nutrition and plant growth regulators.

🧬 Biology — Genetics

Phenotype = observable traits
Genotype = genetic constitution

Practice Mendelian crosses and pedigree-based questions.

📏 Physics — Units & Measurements

SI base units: metre, kilogram, second, ampere, kelvin, mole, candela.

Percentage error = (absolute error / measured value) × 100

⚛️ Chemistry — Atomic Structure

c = νλ
E = hν

Know quantum numbers, electronic configuration and basic spectra.
